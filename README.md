# NoGravity 2.1.0

Локальный патчер и диагностика Google Antigravity для Windows.

## Что делает патч

Автоматически находит обе установки: Desktop (`language_server.exe`) и Antigravity CLI (`agy.exe`, включая установку через PATH). Заменяет `ineligible` на `inexigible`, сохраняя размер каждого файла. CLI поддерживается и без установленного Desktop. Это изменение локальной проверки клиента, а не подтверждение доступа к сервису. Наличие строк не гарантирует совместимость с каждой версией Antigravity.

Если Google отвечает `LOCATION_NOT_ELIGIBLE` или `Detected location: RU`, бинарный патч не меняет этот серверный ответ. Нужна проверка маршрута к Google и определения региона выхода. Геобаза ipinfo может показывать другую страну, чем Google. Сам по себе HTTP 200/401/403/404 на корне домена также не доказывает доступ к моделям.

Замена `AG_LS_PROXY` на `https_proxy` удалена: строки имеют разную длину и сдвигают содержимое exe. При обнаружении такого стороннего хука патчер отказывается от записи; требуется оригинальный бинарник соответствующей версии.

## Запуск

Требования: Windows 10/11 x64 и установленный Antigravity Desktop или CLI. В готовом архиве есть `NoGravity.exe` со встроенным Python: достаточно распаковать архив и запустить `1_Run_NoGravity.bat`.

При запуске из исходников без `NoGravity.exe` нужен Python 3.8+: https://www.python.org/downloads/.

- `1_Run_NoGravity.bat` — меню. Диагностика и пользовательская установка не требуют запуска от администратора.
- `2_Quick_Patch.bat` — локальный патч. Сначала закройте приложение или CLI, который нужно пропатчить. Уже пропатченную открытую установку можно оставить: запись в неё не выполняется. Настройки VPN/DNS автоматически не очищаются.
- `3_Clean_Conflicts.bat` — отдельная очистка известных старых хуков; требуется администратор. Удаляются только правила Google DNS с сервером `127.0.0.53`, переменная `AG_LS_PROXY` и перечисленные в коде старые задачи/процессы.
- `4_Restore_Original.bat` — восстановление из бэкапа той же версии. Старый бэкап от другой версии автоматически не ставится.

Все BAT-файлы используют `run_nogravity.bat`: он запускает `NoGravity.exe`, если тот лежит рядом; иначе проверяет работоспособность Python, поддерживает пути с пробелами и поиск обычных установок без PATH. Не удаляйте этот файл из папки.

Для нестандартной установки задайте `NOGRAVITY_LS_PATH` с полным путём к `language_server.exe` или `NOGRAVITY_CLI_PATH` с путём к `agy.exe` перед запуском.

## Команды

```powershell
python nogravity.py --status       # статус локального патча и последняя региональная ошибка из лога
python nogravity.py --diag         # HTTP-соединение и внешний IP, без обещания доступа к моделям
python nogravity.py --apply        # патч всех найденных установок Desktop и CLI
python nogravity.py --apply --target cli     # только CLI
python nogravity.py --apply --target desktop # только Desktop
python nogravity.py --clean        # отдельная очистка известных конфликтов, от администратора
python nogravity.py --revert       # откат после проверки соответствия бэкапа
python nogravity.py --watch        # проверка патча при входе в Windows
python nogravity.py --unwatch      # удаление задачи
```

Диагностика читает последние 512 КБ `%APPDATA%/Antigravity/logs/language_server.log` и выводит только код ошибки, определённый Google регион и время записи. Это последняя найденная ошибка в логе, она может быть старой. Токены и полные строки лога не выводятся.

## Бэкапы и фоновая задача

Перед записью рядом с каждой установкой сохраняется отдельный оригинал: `language_server.exe.bak_original` или `agy.exe.bak_original`. При смене версии старый бэкап архивируется с SHA-256 в имени, затем создаётся бэкап текущей версии. При ошибке создания бэкапа запись отменяется. Повторное применение уже установленного патча не перезаписывает бэкап.

Фоновая задача запускается **только при входе в Windows**. Обновления Antigravity она не отслеживает. Она использует абсолютный путь к переносимому exe или Python, тот же проверенный патчер для обеих установок и не завершает открытое приложение. После обновления Python или переноса папки переустановите задачу.

## Проверки

```powershell
python -m unittest -v test_nogravity.py
```

Тесты используют временные файлы: проверяют размер exe, сохранение и архивирование бэкапов, отказ при неизвестных сигнатурах, заблокированной записи и работающем приложении, а также различие HTTP-доступности и серверного геоблока.

Лицензия: MIT.

Проверено на Windows 10: Desktop 2.32.1 и CLI 1.5.9. Пропатченная копия CLI выполнила запрос к модели и получила ответ `OK`. Другие версии проверяются по наличию сигнатур; отсутствие сигнатуры отменяет запись. Работа с любым VPN-выходом не гарантируется.

Сборка переносимого exe на Windows: `python -m pip install pyinstaller==6.22.3`, затем `python -m PyInstaller --onefile --console --name NoGravity nogravity.py`. В папке `dist` появится `NoGravity.exe`; положите его рядом с BAT-файлами.
