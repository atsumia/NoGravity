# NoGravity 🚀

> **Autonomous Region Unlocker & Environment Doctor for Google Antigravity**  
> Снятие региональных ограничений Google Antigravity, устранение зависаний и полная совместимость с любыми VPN.

---

## ⚡ О проекте

**NoGravity** — это открытый инструмент для устранения регионального геоблока в **Google Antigravity**, восстановления нативной сетевой маршрутизации и очистки системы от конфликтующих локальных перехватов.

Инструмент решает две ключевые проблемы:
1. **Геоблок аккаунта Google (Protobuf Gating):** Google помечает аккаунты из заблокированных регионов флагом `ineligible: true` в Protobuf-ответе `FetchConfig`. NoGravity нейтрализует эту проверку на уровне бинарника языкового сервера.
2. **Зависание на старте («Серый экран» / ERR_TIMED_OUT):** При использовании сторонних утилит или попытке перехода на чистый VPN языковой сервер часто остаётся привязанным к локальному несуществующему прокси (`AG_LS_PROXY` на порт 53129) или зависшему DNS-перехвату (NRPT на `127.0.0.53`). NoGravity возвращает приложению нативную поддержку системного прокси (`https_proxy`) и очищает системные перехваты.

## 🛠 Возможности

- 🎯 **Точечный бинарный патч (Zero-Side-Effects):** 
  - Замена `ineligible` → `inexigible` (нейтрализация проверки геоблока в парсере Protobuf).
  - Замена `AG_LS_PROXY` → `https_proxy` (возврат к стандартной сетевой модели).
- 🛡 **Оригинальный бэкап:** При первом патчинге создаётся резервная копия `language_server.exe.bak_original`. Откат в заводское состояние возможен в любой момент в 1 клик.
- 🧹 **Очистка конфликтов:** Остановка зависших демонов (`ag_dns`), удаление фоновых задач автозапуска и очистка таблиц NRPT DNS.
- 🌐 **Работает с любым VPN:** Полная совместимость с **Happ**, **v2rayN/NG**, **Clash**, **Sing-box**, **WireGuard**, **OpenVPN** и корпоративными SOCKS5/HTTP прокси.
- 🩺 **Встроенный сетевой доктор:** Диагностика доступности эндпоинтов Google AI (`cloudcode-pa.googleapis.com`, `aicode.googleapis.com`, `gemini.google.com`) с замером пинга и детекцией блокировок.
- 🔄 **Авто-сохранение патча (Watchdog):** Опциональная фоновая задача в планировщике, которая автоматически поддерживает патч после авто-обновлений Antigravity.

## 🚀 Быстрый запуск

### Вариант 1. Интерактивное меню (Рекомендуется)
Запустите файл от имени администратора:
```
1_Run_NoGravity.bat
```
Откроется консольный терминал со статусом системы и удобным меню управления [1–5].

### Вариант 2. Быстрый патч в 1 клик
```
2_Quick_Patch.bat
```
Автоматически снимет геоблок, очистит конфликтующие хуки и подготовит Antigravity к запуску через ваш VPN.

### Вариант 3. Аварийная очистка конфликтов
```
3_Clean_Conflicts.bat
```
Снимает все сторонние сетевые перехваты, демоны DNS и правила реестра без модификации файлов.

### Вариант 4. Откат к заводской версии
```
4_Restore_Original.bat
```
Возвращает оригинальный нетронутый файл `language_server.exe` из бэкапа.

## 📋 Системные требования

- **ОС:** Windows 10 / Windows 11 (64-bit)
- **Установленный Google Antigravity**
- **Python 3.8+** (если не установлен — `winget install Python.Python.3.11` в терминале)
- Любой рабочий VPN с выходом за пределы РФ (например, Happ или V2Ray).

> [!NOTE]
> **Важное замечание про Cloudflare WARP:**  
> Эндпоинты Google CloudCode (`cloudcode-pa.googleapis.com`) блокируют IP-диапазоны Cloudflare WARP с ошибкой `400: User location is not supported`.  
> Если в вашем VPN настроен выход через WARP, настройте прямое проксирование (`direct`) для доменов `*.googleapis.com` и `*.google.com` через чистые IP нод (Амстердам, Франкфурт, Хельсинки и т.д.).
